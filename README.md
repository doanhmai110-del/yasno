# Ясно

Расширение для Chrome: открыли английский сайт — он стал русским и таким остаётся при прокрутке и кликах.

## Скачать

https://github.com/doanhmai110-del/yasno/archive/refs/heads/main.zip

Или страница: https://github.com/doanhmai110-del/yasno → **Code** → **Download ZIP**.

## Установка

1. Распакуйте архив. Появится папка `yasno-main`.
2. Chrome → `chrome://extensions` → режим разработчика.
3. **Загрузить распакованное расширение** → папка `yasno-main`.

Если расширение уже стоит: на `chrome://extensions` нажмите **Обновить** у ярлычка Ясно, затем обновите страницу сайта.
