# Ясно

Расширение для Chrome: открыли английский сайт — он стал русским и таким остаётся при прокрутке и кликах.

## Скачать одним файлом

Откройте эту ссылку **в обычной вкладке Chrome** (не в окне чата):

https://github.com/doanhmai110-del/yasno/archive/refs/heads/main.zip

Или на странице репозитория: зелёная кнопка **Code** → **Download ZIP**.

https://github.com/doanhmai110-del/yasno

## Как поставить

1. Распакуйте архив. Появится папка `yasno-main`.
2. В Chrome откройте `chrome://extensions`.
3. Включите **Режим разработчика** справа сверху.
4. Нажмите **Загрузить распакованное расширение**.
5. Выберите папку `yasno-main` (в ней должен быть файл `manifest.json`). Не выбирайте сам zip.

Готово. Откройте любой английский сайт — перевод начнётся сам. Пауза: **Alt+T**.
