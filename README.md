# Ясно

Расширение Chrome: английский сайт становится русским и остаётся таким при прокрутке.

Версия **1.2.0** — починен отвал перевода, когда Google отвечал ошибкой.

## Скачать

https://github.com/doanhmai110-del/yasno/archive/refs/heads/main.zip

## Установка / обновление

1. Удалите старую папку `yasno-main`, если она есть.
2. Распакуйте новый архив.
3. Chrome → `chrome://extensions` → режим разработчика.
4. Удалите старое расширение Ясно, затем **Загрузить распакованное** → новая папка `yasno-main`.
5. Обновите вкладку сайта. В списке расширений должна быть версия **1.2.0**.
